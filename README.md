# THM – Studiumplus Vorlagen
Dadurch dass die THM und StudiumPlus keinerlei LaTeX Vorlagen bereitstellt haben wir nach den Vorgaben unsere eigene gebaut.

Dieses Repo ist dazu da wissenschaftliche LaTeX Vorlagen für die THM und StudiumPlus bereitzustellen. Diese Vorlegen sind **NICHT** offiziell, aber funktionieren und werden allgemeine erstmal akzeptiert.
Gerne vor Verwendung mit den Betreuenden absprechen, ob die Form so okay ist. Eine Beispiel PDF ist im Repo vorhanden.

## Zitierstile
Der hier angewandte Zitierstil ist ein Fußnotenzitierstil. Dieser lässt sich aber sehr leicht ändern. Den am besten mit eurem Unternehmenbetreuenden absprechen, die Profs haben da meistens eine eigene Preferenz und können euch genau sagen was sie wie haben wollen.

## Firmenlogo
Das Firmenlogo ist unten rechts auf der Titelseite es ist optional und lässt sich mit dem ersetzen der `firmenlogo.png` veräandern. Da einfach mit der im Code einegestellen Höhe spielen und ggf. auch mit irgendwelchen \vpsace Befehlen, damit das alles auf einer Seite ist.
